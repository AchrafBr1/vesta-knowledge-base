# wizard1-setup-vesta-home-ip-cam

**Add to Equipment**

Your camera connects directly to the control panel through

&#x20;local interface and cloud. This enables advanced features

such as image capture, alarm-linked snapshots, and event

&#x20;detection (if supported by the camera).

&#x20;

**Add to Cloud**

Use this mode for battery-powered cameras,

such as solar cameras. It supports live streaming,

playback, and basic camera settings.
